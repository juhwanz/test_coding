# 소수 만들기

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12977
- 교재: stage1/day1 · 대체 (다른 단계에도 나옴: stage2/A/u08 )
- 상태: 풀이 참고
- 풀이 시간: (직접 적기: ○분, 힌트 받은 시점 ○분, 풀이 본 시점 ○분)
- 제한: nums 길이 3~50, 원소 1~1,000 자연수, 중복 없음

## 풀이 메모

- 처음 접근: N ≤ 50이라 3중 for문(50³ = 12만 5천)이면 된다고 판단
- 핵심 아이디어: j는 i+1, k는 j+1부터 돌려 서로 다른 세 개만 고르고, 합을 isPrime으로 검사. 소수 판별은 2부터 √x까지(d * d <= x) 나눠 본다
- 시간·공간복잡도: (직접 적기)
- 막힌 곳: 소수 판별을 코드로 못 짬. nums.length()처럼 괄호를 붙임, j·k를 i·j와 같은 칸에서 시작함

# 문자열 다루기 기본

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12918
- 교재: stage1/day1 · 대체
- 상태: 혼자 성공
- 풀이 시간: (직접 적기: ○분)
- 제한: s 길이 1~8, 영문 대소문자 또는 숫자. 길이가 4 또는 6이고 숫자로만 되어 있으면 true

## 풀이 메모

- 처음 접근: 문자를 하나씩 보며 숫자가 아니면 false
- 핵심 아이디어: 길이 4 또는 6 먼저 확인, 숫자 판별은 문자끼리 비교 ('0' ≤ a ≤ '9')
- 시간·공간복잡도: O(N) / O(N) (toCharArray), N ≤ 8
- 막힌 곳: a > 9처럼 문자와 정수를 비교함 ('0'은 48). 길이 조건 빠뜨림. boolean 철자

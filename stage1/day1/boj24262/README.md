# 알고리즘 수업 - 알고리즘의 수행 시간 1

- 링크: https://www.acmicpc.net/problem/24262
- 교재: stage1/day1 · 필수
- 상태: 풀이 참고
- 풀이 시간: (직접 적기: ○분, 풀이 본 시점 ○분)
- 제한: 1초, 512MB, 1 ≤ n ≤ 500,000

## 풀이 메모

- 처음 접근: 문제가 무엇을 묻는지 몰랐음
- 핵심 아이디어: 주어진 코드에 반복문이 없어서 코드1은 n과 상관없이 1번 실행 → 수행 횟수 1, 최고차항 차수 0 (1 = n⁰)
- 시간·공간복잡도: O(1) / O(1)
- 막힌 곳: 함수를 구현하는 문제가 아니라, 주어진 코드의 수행 횟수와 차수를 세는 문제라는 걸 못 알아챔

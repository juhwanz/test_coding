# 최소, 최대

- 링크: https://www.acmicpc.net/problem/10818
- 교재: stage1/day1 · 필수
- 상태: 혼자 성공
- 풀이 시간: (직접 적기: ○분)
- 제한: 1초, 256MB, 1 ≤ N ≤ 1,000,000, 각 정수 -1,000,000 ~ 1,000,000

## 풀이 메모

- 처음 접근: N개를 한 번씩 읽으면서 min·max 갱신
- 핵심 아이디어: min·max 처음 값을 문제 범위 끝값(1,000,000 / -1,000,000)으로 두고 비교
- 시간·공간복잡도: O(N) (for문 하나) / O(1) (배열 없이 하나씩 비교)
- 막힌 곳: StringTokenizer에 nextInt()를 씀 → nextToken() (Scanner와 헷갈림)

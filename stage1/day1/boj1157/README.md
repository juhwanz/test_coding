# 단어 공부

- 링크: https://www.acmicpc.net/problem/1157
- 교재: stage1/day1 · 필수
- 상태: 풀이 참고
- 풀이 시간: (직접 적기: ○분, 풀이 본 시점 ○분)
- 제한: 2초, 128MB, 단어 길이 ≤ 1,000,000, 알파벳 대소문자만

## 풀이 메모

- 처음 접근: 26칸 빈도 배열로 세고, 최댓값과 그 개수를 확인
- 핵심 아이디어: 소문자로 한 번 바꾼 뒤 ch - 'a'로 칸 번호. 최댓값이 2개 이상이면 ?, 아니면 (char)(num + 'A')
- 시간·공간복잡도: O(N) / O(1) (배열 26칸)
- 막힌 곳: 반복문 안에서 toLowerCase() → O(N²). 백준 main에서 return으로 답을 냄. num + 'a'가 int라 숫자로 출력됨

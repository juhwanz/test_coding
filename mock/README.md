# 모의 코테 기록

한 번 볼 때마다 `mock/YYYY-MM-DD.md` 기록 파일을 하나 만들고, 문제 폴더는 같은 날짜 폴더에 만든다.

```bash
./new boj 2615 mock/2026-12-01     # → mock/2026-12-01/boj2615
./run mock/2026-12-01/boj2615
```

- 문제는 아직 안 푼 것으로, 유형을 모르게 고른다. `stage*` 폴더에 만들면 단원이 드러난다
- 시험 중에는 AI를 쓰지 않는다 (AGENTS.md 4-5). `./run`만 쓴다
